# 番茄钟应用 - 产品需求文档 (PRD)

> 版本: v1.0 | 项目: pomodoro-app | 日期: 2026-06-03

---

## 1. 产品概述

一个简洁的在线番茄钟应用，帮助用户通过番茄工作法提高专注力。

## 2. 核心功能

### 2.1 番茄计时
- 默认 25 分钟专注倒计时
- 5 分钟短休息
- 15 分钟长休息（每4个番茄后）
- 开始/暂停/重置计时器

### 2.2 任务管理
- 添加今日待办任务
- 标记任务完成
- 关联番茄钟到任务

### 2.3 统计
- 今日完成番茄数
- 总专注时长

## 3. 技术架构

### 3.1 后端 (Node.js + Express)
- RESTful API
- 数据存储: JSON 文件（本地开发）
- API 端口: 3001

### 3.2 前端 (React + Vite)
- 单页应用
- 响应式设计
- 开发端口: 5173

## 4. API 设计

### 4.1 任务管理
- `GET /api/tasks` - 获取今日任务列表
- `POST /api/tasks` - 创建任务
- `PATCH /api/tasks/:id` - 更新任务（完成/未完成）
- `DELETE /api/tasks/:id` - 删除任务

### 4.2 番茄统计
- `GET /api/stats` - 获取今日统计

## 5. 数据结构

### Task
```json
{
  "id": "uuid",
  "text": "写代码",
  "completed": false,
  "createdAt": "ISO8601"
}
```

### Stats
```json
{
  "totalPomodoros": 3,
  "totalFocusMinutes": 75,
  "date": "2026-06-03"
}
```

## 6. 页面设计

### 主页面
- 中央大计时器
- 下方任务列表
- 统计概览
- 状态: 专注 / 短休息 / 长休息
